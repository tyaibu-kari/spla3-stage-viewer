スプラ ステージビューアー(配布版)
====================================

■ これは何？
スプラトゥーン3のステージ画像(平面図・ブキ射程表つき)を、モード別・
ステージ別に一覧から選んで表示できる、完全オフラインで動くWebアプリです。
外部サーバーには一切通信しません(three.jsも同梱済み)。

 ・平面図の上に手描き注記や図形(矢印・線・丸など)を書き込める
 ・4対4のプレイヤー配置と、ブキ・スペシャルの射程を円で表示できる
 ・プレイヤーごとに「ギア」タブでギアパワーを入力すると、ヒト移動速度
   アップや対物攻撃力アップなどの効果の目安が確認できる
 ・平面図をもとに簡易3Dモデルを自動生成し、マウスで回転させながら
   位置関係を確認できる

■ 使い方(はじめに1回だけ)
1. ダウンロードしたzipファイルを、好きな場所に丸ごと展開(解凍)してください。
   ※展開したフォルダの中身(index.html・画像フォルダなど)は、フォルダ構成を
   崩さずそのままにしてください。画像フォルダを移動/リネームすると、
   一覧から画像が表示されなくなります。
2. フォルダの中の index.html をダブルクリックして、ブラウザ(Chrome / Edge
   など比較的新しいブラウザ推奨)で開いてください。
3. 左サイドバーでモード(ナワバリ/エリア/ヤグラ/ホコ/アサリ)を選び、
   ステージ名をクリックすると中央に平面図が表示されます。
4. インストールや会員登録は不要です。ネット接続も不要です。

■ 「平面図・注記」タブ
 ・ペン/直線/矢印/四角/楕円/定規/コンパス/テキスト/消しゴム/選択(移動) の
   各ツールが使えます。色と太さはツールバーで変更できます。
 ・書き込みはステージごとに自動保存され(ブラウザのlocalStorage)、
   次回同じ画像を開いたときも復元されます(このパソコン・このブラウザの
   中だけに保存され、外部には送信されません)。
 ・「🖼 画像として保存」で、注記込みの画像をPNGとしてダウンロードできます。
 ・Delete: 選択中の図形/プレイヤーを削除 / Ctrl+Z: 元に戻す /
   Ctrl+Shift+Z (または Ctrl+Y): やり直す
 ・右クリックを押しながらドラッグ: その場だけ消しゴムとして使えます。
 ・マウスホイール(中央ボタン)を押しながらドラッグ: 画像の表示位置を移動。

 ・「プレイヤー配置(4対4)」: ツールバー下の専用行から、
   「🔵 味方を配置」「🟠 相手を配置」でそれぞれ最大4人まで配置できます。
   マーカーをダブルクリックすると、ブキ種別・ブキ名・スペシャル名を
   選ぶ画面が開きます。「射程を円で表示する」にチェックを入れて保存すると、
   そのブキの射程を半径とした円が表示されます(要:射程スケールの校正)。

 ・「ギア」タブ(NEW): プレイヤー編集画面の上部にある「🛡 ギア」タブから、
   頭/服/靴それぞれのメイン・サブギアパワーを選択できます。
     - ヒト移動速度アップなど、AP(ギアパワーポイント)で段階的に効果が
       伸びるギアパワーは、AP合計と「効果進行度(0〜100%)」の目安を表示します。
     - 対物攻撃力アップ(靴限定)など、メイン専用のギアパワーは、装備の
       有無と、対象物ごとの倍率の目安を一覧表示します。
     - 表示される数値は検証情報をもとにした目安です。ブキごとの基準値の
       違い(実際の移動速度や与ダメージの絶対値)までは反映していません。
       あくまで「このAPだとどれくらい効果が伸びているか」の参考としてご利用ください。

 ・「スペシャル配置」: プルダウンでスペシャル名を選び「➕ 配置」で配置。
   ダブルクリックで射程1/射程2/爆風込み射程の表示・非表示を切り替えできます。

 ・「📏 射程スケールを設定」: 各ステージ画像に印刷されている射程の目盛りに
   対して1回だけ校正すると、以後そのステージでは正しい縮尺で射程円が
   表示されます(ステージごとに保存されます)。
   ブキ・スペシャルの射程データはスプラトゥーン3の公式ブキ表を参考にした
   目安値です(リッター4Kの射程6.2を基準にしています)。

■ 「3Dモデル」タブ
 ・左側の平面図編集エリアで「エリア(高さ)」「壁/段差」を配置すると、
   右側に簡易3Dモデルがリアルタイムに表示されます。
   左ドラッグ:回転 / 右ドラッグ:平行移動 / ホイール:ズーム

■ データの保存・バックアップについて
 ・注記・プレイヤー配置・ギア設定・3D設定は、いずれもブラウザ内
   (localStorage)にのみ保存されます。他の人や外部には送信されません。
 ・ブラウザのキャッシュ/閲覧データを消去すると、書き込みが消えてしまう
   可能性があります。ヘッダーの「⤓ データ書き出し」で、全ステージ分の
   データを1つのJSONファイルに書き出せます。「⤒ データ読み込み」で
   復元できます。定期的なバックアップをおすすめします。

■ 画像を追加・変更したい場合
 ・このアプリは配布用のため、画像一覧(manifest.js)の再生成には対応した
   ツール(Claude等)が別途必要です。同梱の画像を使う分には何も操作は
   不要です。
 ・ヘッダーの「📁 画像フォルダを追加」ボタンから、その場限りで別の画像を
   一時的に追加読み込みすることもできます(ブラウザを閉じると解除されます)。

■ フォルダ構成
 index.html      ... アプリ本体(これを開く)
 app.js          ... アプリのロジック
 gear.js         ... ギアパワー(アビリティ)のデータ・計算ロジック
 manifest.js     ... 同梱画像の一覧
 weapons.js      ... ブキ/スペシャルの名称・射程データ
 vendor/         ... 3D表示に使うthree.js(オフライン同梱)
 画像（ナワバリ）-ブキ射程表あり 等 ... ステージ画像フォルダ
